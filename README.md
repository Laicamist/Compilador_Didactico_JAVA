# Compilador_Didactico_JAVA
Simulador didáctico del compilador de Java (Lenguajes y Autómatas II). Aplicación multiplataforma (KMP) que replica de forma visual e intuitiva el análisis léxico, sintáctico y semántico, incluyendo tablas de símbolos y errores, árboles de ejecución y generación de código intermedio optimizado.
